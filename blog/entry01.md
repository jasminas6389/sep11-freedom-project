## Picking My Tool
For my Freedom Project I decided to pick the tool **Kaboom.js**. With this tool I decided I could make an obstacle avoiding game, where a patient would be leaving a hospital and they are trying to get home safely without getting sick, and avoiding the dangers of the streets. Before I can start my project and get into coding, first I need to learn my tool. I decided to use Kaboom.js because it allows me to create different objects, characters, and environments for my game. I wanted a tool that would help me create the scenes and objects that I need for my project.

## How I started learning
I didn't know where to start so I looked at examples on the Kaboom.js website, and used the playground to experiment with different codes. But I also made sure to have a file in my IDE where I tinker with Kaboom.js

**What I learned**
|Code |Output|
| --- | --- |
|  add() | creates, objects and adds them to the screen|
|  pos() | controls where an object is placed|
|  circle() | makes a circle|
|  rect() | creates rectangles|
|  setGravity() | makes a character fall from the top of the screen|
|  body() | allows gravity to affect an object|
|  solid() | stops objects from passing through each other|
