# Entry 1
##### 11/11/26

## Picking My Tool
For my Freedom Project I decided to pick the tool [**Kaboom.js**](https://kaboomjs.com/). With this tool I decided I could make an obstacle avoiding game, where a patient would be leaving a hospital and they are trying to get home safely without getting sick, and avoiding the dangers of the streets. Before I can start my project and get into coding, first I need to learn my tool. I decided to use Kaboom.js because it allows me to create different objects, characters, and environments for my game. I wanted a tool that would help me create the scenes and objects that I need for my project.

## How I started learning
I didn't know where to start so I looked at examples on the Kaboom.js website, and used the playground to experiment with different codes. But I also made sure to have a file in my [**IDE**](https://redesigned-space-succotash-69xvwgr9xwqjf4x4j.github.dev/)  where I tinker with Kaboom.js.

**What I learned**
|Code |Output|
| --- | --- |
|  add() | creates, objects and adds them to the screen|
|  pos() | controls where an object is placed|
|  circle() | makes a circle|
|  rect() | creates rectangles|
|  setGravity() | makes a character fall from the top of the screen|
|  body() | allows gravity to affect an object|
|  solid() | stops objects from passing through each other|

I also watched a video from the channel Ourcade called [**5 Tips for Getting Started with Kaboom.js**](https://youtu.be/iRXI6ThRJvM?si=g9gvjiTFAPfF0zID). This helped me learn more about creating objects, collisions, animations, and game levels.

### How I Tinkered With Kaboom.js 
First I made a new file in my IDE called `kaboom.html`, I started by making a simple scene with a blue background, grass, a sun, a tree, and a pink character with eyes. Then I started To make the body for the character. Then I added a hospital because it connects to my game idea. I created a hospital building using rectangles and added a roof, the word "HOSPITAL," a red cross, and six windows. 

I used width, height, and background to create the setting. I also used rect() to make the grass and building, pos() to position objects, and text() to add the hospital sign.

**My Beach Scene** <br>
Another way I tinkered with Kaboom.js was making a beach scene. I really missed summer so I wanted to create something relaxing with blue skies, ocean water, and golden sand. I also added a sun, a palm tree, an umbrella, and my character. I used rect() to create the sand, ocean, the tree, and the umbrella. I used  circle() to create the sun, palm tree leaves, and an umbrella top. I also used different color() and pos() codes to make everything look the way I wanted.

**Challenge** <br>
One challenge I faced was when I was creating my palm tree. I originally put the leaves before the tree trunk, which made the tree look weird because the trunk appeared on top of the leaves. But then I remembered that the order I put objects in matters in JavaScript. I switched the order and placed the trunk first and the leaves after, which fixed the problem.

## Engineering Design Process
I am still in the beginning stages of my Engineering Design Process. We haven't actually started making our project yet because first we are making sure we fully learn our tool. I have been trying new things with codes, creating scenes, and learning how to add objects to the screen. Creating the hospital scene has helped me start thinking about what my actual game could look like. I am also learning how to create different objects that I might eventually use as obstacles. My next steps are going to be learning more about Kaboom.js, experimenting with new and more codes, and also to figure out how to make objects move and interact with each other. Once I learn more, I can make my obstacle game.


## Skills
* **Problem-Solving**: I improved my problem-solving skills by learning how to figure out what was wrong with my code and how to fix it. For example, when my palm tree didn't look right, instead of giving up I went back into my code and went over everything again to find the issue. Then I realized I had placed the objects in the wrong order. This taught me to think through problems and find solutions on my own.


* **Patience**: I learned that coding takes patience because things don't always work the first time. Sometimes I had to go back and make changes to the position, size, or color of my objects. I learned that it's important to take my time and not get frustrated when something doesn't work right away. Some code really tests my patience when It doesn't do what I want it to, but I just take a break and get back to it when I'm calm.


* **Creativity**: I improved my creativity by learning how to turn my ideas into actual scenes using code. I got to experiment with different colors, shapes, and objects to create my hospital and beach scenes. I also learned that I can use simple shapes to create different things and bring my ideas to life.
